# L&H PULSE — Proyecto de Ingeniería de Software I (ETITC)

Herramienta de gestión comercial de las tiendas de L&H: cumplimiento de metas, rankings de tiendas y asesoras,
y carga de los informes de ventas en Excel.

**Equipo:** Santiago León · Camilo Torres · Thaira Hernández · Jonathan Monroy

Versión académica: sin datos reales (ventas, correos, contraseñas ni dirección del servidor).

## Sprint 1

API Flask conectada a PostgreSQL (Docker) con inicio de sesión, ranking de desempeño y carga del Excel de ventas.
Copie `.env.example` como `.env`, complete los valores y ejecute `docker compose up -d`.
